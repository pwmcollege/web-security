Try a `;` or a quote now, and the server rejects your request before starting a shell. The developer has traded quoted input for a *blocklist*, a list of characters the application refuses to accept. The list includes backslashes and many other characters used in shell syntax too, leaving you with far fewer ways to express a command.

That's a lot of forbidden punctuation, but the shell still receives a command containing your unquoted text and interprets whatever the filter lets through. You now have to satisfy two programs: pass the application's character check while still making the shell do more than render a banner.
