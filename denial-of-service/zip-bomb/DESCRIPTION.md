Suppose you need to store a million copies of the same sentence. You could write out all million, or store the sentence once along with instructions for repeating it. The second representation is much smaller, yet both describe exactly the same content. Lossless compression takes advantage of patterns like this to represent data in fewer bytes. Decompression reconstructs the original, repetitions and all.

ZIP bombs make that reconstruction expensive. You send a small archive, and the server supplies the processing time and storage needed to unpack its much larger contents. An upload size check sees only the compressed archive, so it can accept a file whose extracted contents are far beyond what the server has room or time to handle. And better compression only makes the upload cheaper without reducing the amount of data the server must produce.
