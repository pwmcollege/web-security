Regular expressions, or regexes, gave text editors a way to find things like timestamps in a log, where each line can have a different time written in the same format. You tell a tool like `grep` where to expect the digits and separators, and it checks each line of the file and prints the ones that contain a timestamp that fits. Web apps use the same kind of matching to check what someone typed into a form or let people search for words by pattern.

Once a match becomes part of a web request, the worker handling it stays busy until the matcher finishes, so the time spent on a search comes out of the same capacity the server uses to answer other visitors. A regular expression denial of service (ReDoS) occurs when matching consumes enough of that capacity to leave ordinary requests waiting in the queue until they time out.
